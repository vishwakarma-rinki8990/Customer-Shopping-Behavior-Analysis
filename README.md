# 🛒 Customer Shopping Behavior Analytics

## 📝 Project Overview
This project demonstrates an **end-to-end analytics workflow** combining Python, SQL, and Power BI to analyze customer shopping behavior.  
The goal is to uncover insights into purchase trends, customer loyalty, and revenue drivers, and present them through interactive dashboards and a final business report.

---

## ⚙️ Tech Stack
- **Python**: Data cleaning, exploratory data analysis (EDA), and modeling  
- **SQL**: Customer segmentation, loyalty analysis, and purchase driver queries  
- **Power BI**: Interactive dashboards with slicers and clustered charts  
- **Reporting**: Business insights and recommendations  

---

## 🚀 Workflow
1. **Data Preparation (Python)**  
   - Clean raw datasets  
   - Perform exploratory data analysis (EDA)  
   - Build simple models for trend analysis  

2. **Segmentation (SQL)**  
   - Identify customer segments by age group  
   - Loyalty and repeat purchase analysis  
   - Revenue drivers  

3. **Visualization (Power BI)**  
   - Clustered column charts: *Sales by Age Group* & *Revenue by Age Group*  
   - Slicers for dynamic filtering  
   - KPIs and trend visuals  

4. **Reporting**  
   - Consolidated findings  
   - Actionable business recommendations  

---

## 📈 Key Insights
- Younger age groups drive higher sales volume  
- Revenue concentration in middle-aged customer segments  
- Loyalty programs show measurable impact on repeat purchases  
- Interactive dashboards enable quick filtering by demographics  

---

## 📂 Project Structure
- `data/` → Raw datasets  
- `notebooks/` → Python scripts for cleaning, EDA, and modeling  
- `sql/` → Queries for segmentation and loyalty analysis  
- `dashboard/` → Power BI files with interactive visuals  
- `report/` → Final report with insights and recommendations
